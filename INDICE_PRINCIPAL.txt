📈 FORMATO DEL DATASET FINAL
═════════════════════════════════════════════════════════════════════════════

Cada imagen se convierte en:
  [píxel_0, píxel_1, ..., píxel_16383, etiqueta]
   └─────── 16,384 elementos ─────────┘    └─ 0 o 1

Donde:
  • 0-16383: Matriz 128×128 aplanada (1=blanco, 0=objeto)
  • Etiqueta: 1 si hay contaminación, 0 si no hay

Compatible con:
  ✓ Scikit-learn        ✓ XGBoost
  ✓ TensorFlow/Keras    ✓ LightGBM
  ✓ PyTorch             ✓ Redes neuronales

    (16,384 elementos + etiqueta)
